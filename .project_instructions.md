## Architecture Notes
- **Supabase Management API:** `POST https://api.supabase.com/v1/projects/eulbaaiumpizuprxtozq/database/query` with Bearer `[HIDDEN_TOKEN]` — used for schema changes.
- **Tables (key ones):** companies, profiles, clients, products, invoices, invoice_items, fiscal_config, audit_logs, **erp_integrations**, **erp_sync_log**
- **No `code` column on `products`** → SAF-T uses `slugCode(name)` to derive product codes.
- **`invoice_items` has NO `product_id`** → dedup by description+tax_rate.
- **`companies` has NO `business_name`** → falls back to `name` for SAF-T.
- **`fiscal_config.saft_modo`:** 'producao' → SourceBilling `P`, 'teste' → `T`

## SAF-T (AO) Generator — `lib/saft.ts`
- v1.04_AO compatible (based on SAF-T PT v1.04)
- `CustomerID` is **always NIF** (consistent across `<Customer>` and `<Invoice>`)
- `<TaxTable>` present with all unique rates (NOR/ISE)
- Products derived from invoice items when master catalog is empty
- `<References>` inside `<Line>` (first line only) for NC/ND — with Reference + Reason
- NC uses `<DebitAmount>`, everything else `<CreditAmount>`
- `<BusinessName>`, `<ProductCompanyTaxID>`, `<SoftwareCertificateNumber>` in Header
- No non-standard `<Signature>` tag

## ERP Integration (Odoo — first target)
- **Files:**
  - `lib/erp/types.ts` — shared types
  - `lib/erp/odoo.ts` — JSON-RPC client (authenticate, pushClients/Products/Invoices)
  - `app/api/erp/route.ts` — GET/POST/DELETE integration config
  - `app/api/erp/test/route.ts` — test connection
  - `app/api/erp/sync/route.ts` — manual sync (clients/products/invoices/all)
  - `app/api/erp/logs/route.ts` — sync history
  - `components/views/erp-integration-panel.tsx` — UI tab
- **Push only (MVP):** Top Fatura → Odoo. Invoices go in as draft `account.move` (user validates in Odoo).
- **Auth:** Odoo API key (preferred over password). Stored in `erp_integrations.api_key`, never returned to client.
- **Match criteria:**
  - Partners: by `vat` (NIF)
  - Products: by `name`
  - Invoices: by `ref` (invoice_number) — skip if already exists
- Future: bi-directional sync, webhooks, more providers (Primavera, Sage, SAP)
